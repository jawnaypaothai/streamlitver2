# วิเคราะห์คาน Determinate ด้วย Streamlit

แอปพลิเคชันนี้สร้างขึ้นด้วย Python + Streamlit สำหรับวิเคราะห์คานแบบกำหนดได้ (Determinate Beam Analysis) พร้อมแสดง SFD และ BMD

## วิธีใช้งานบน Streamlit Cloud

1. สร้าง GitHub Repository และอัปโหลดโฟลเดอร์นี้ทั้งหมด
2. ไปที่ https://streamlit.io/cloud
3. คลิก “New App” และเชื่อมกับ GitHub Repo ของคุณ
4. เลือก `indeter.py` แล้วคลิก Deploy
